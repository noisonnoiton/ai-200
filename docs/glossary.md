# 용어집

| 용어 | 의미 |
| --- | --- |
| ACR | Azure Container Registry. Container image 저장 및 build service |
| AKS | Azure Kubernetes Service. Managed Kubernetes platform |
| Binding | Azure Functions에서 service input/output 연결을 선언하는 방식 |
| Change feed | Cosmos DB item 생성과 변경의 순서화된 기록 |
| Consistency level | 분산 replica에서 read freshness와 availability의 균형 |
| Dead-letter queue | 반복 처리에 실패하거나 전달할 수 없는 message 보관 위치 |
| Embedding | Text나 image의 의미를 수치 vector로 표현한 값 |
| Idempotency | 같은 작업을 반복 실행해도 추가 side effect가 생기지 않는 성질 |
| KEDA | Event source를 기준으로 Kubernetes workload를 scale하는 component |
| KQL | Azure Monitor와 Log Analytics data를 조회하는 query language |
| Metadata filter | Vector similarity search 전에 category, tenant 등의 조건으로 범위를 제한하는 방법 |
| OpenTelemetry | Trace, metric, log를 생성하고 전달하는 vendor-neutral observability 표준 |
| pgvector | PostgreSQL에서 vector 저장과 similarity search를 제공하는 extension |
| RAG | 검색한 근거를 model prompt에 결합해 response를 생성하는 pattern |
| Revision | Container Apps application의 immutable deployment version |
| RU | Cosmos DB operation이 소비하는 Request Unit |
| Span | Distributed trace 안의 개별 operation 단위 |
| Vector similarity search | Query vector와 가까운 stored vector를 찾는 검색 |
