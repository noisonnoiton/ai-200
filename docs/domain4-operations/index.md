# Domain 4: Secure and operate

**시험 비중: 20–25%**

Production readiness는 기능 구현 이후의 작업이 아닙니다. Identity, secret, configuration, telemetry를 application design에 포함해야 합니다.

## 학습 목표

- Key Vault에서 secret을 retrieve하고 rotation에 대응합니다.
- App Configuration에서 non-secret setting과 feature configuration을 관리합니다.
- OpenTelemetry로 distributed trace, metric, log correlation을 구성합니다.
- KQL로 Azure Monitor와 Application Insights telemetry를 분석합니다.

!!! info "공식 자료"
    [Azure Key Vault documentation](https://learn.microsoft.com/en-us/azure/key-vault/), [Azure App Configuration documentation](https://learn.microsoft.com/en-us/azure/azure-app-configuration/), [Azure Monitor documentation](https://learn.microsoft.com/en-us/azure/azure-monitor/)
